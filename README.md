# CUTWORK

Turn long videos into short vertical clips. CUTWORK transcribes a video, marks and
scores the best moments, and exports 1080x1920 clips with word-by-word captions.
It is free and runs on your own computer.

- **Website:** https://riotolondon.github.io/cutwork/
- **The app:** [`cutwork-clipper/`](cutwork-clipper/) (set-up steps are in its README)
- **The website's source:** [`docs/`](docs/)

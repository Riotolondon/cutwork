How it works

Three steps from upload to clips

You stay in control of every cut. CUTWORK does the slow parts.

STEP 1

Add a video

Upload a file, point to one on your computer, or paste a link. CUTWORK transcribes every word with its timing.

STEP 2

Review the marked moments

The strongest moments are scored and ranked. Preview each one, fix the start and end, and type an on-screen hook.

STEP 3

Export

Tick the moments you want. Each becomes a 1080×1920 clip, filed in a folder named after the video.

Features

What you get in every clip

Word-by-word captions

Bold captions burned into the video, with the spoken word highlighted as it is said.

Framing that follows the speaker

The vertical crop centres on the speaker's face. Screen recordings keep the whole frame on a blurred background.

Moments scored for you

Strong opening lines, numbers, on-topic keywords and clean endings score higher. Set your own niche keywords.

Sharper picks with Claude

Copy the transcript to Claude and paste its reply back. Its picks appear at the top with hooks written.

Private by design

Transcription and rendering happen on your computer. Your videos are not uploaded to a CUTWORK server.

Cloud copy

If OneDrive is set up on your computer, a copy of each finished clip is placed there so it syncs to your other devices.

Get started

Install in a few minutes

  1. Install Python 3.10 or newer from python.org. On Windows, tick "Add Python to PATH".
  2. Install ffmpeg. Windows: winget install Gyan.FFmpeg. Mac: brew install ffmpeg. Linux: sudo apt install ffmpeg.
  3. Download CUTWORK from GitHub (Code, then Download ZIP) and unzip it.
  4. Open the cutwork-clipper folder. On Windows, double-click run.bat. On Mac or Linux, run ./run.sh.
  5. The app opens in your browser. The first start installs what it needs, which takes a few minutes.

Questions

Good to know

Is it really free?

Yes. The app is open source and free to run. Free clips carry the CUTWORK watermark. A paid Pro plan that removes it is planned.

How long does a video take?

On a normal laptop, transcription takes roughly a quarter of the video's length on the Balanced setting. Each clip then takes about a minute to export.

Do my videos leave my computer?

No. Transcription and rendering run locally. If you choose to use Claude for sharper picks, only the transcript text you paste goes to Claude.

Which videos can I clip?

Only clip videos you have permission to use, such as your own recordings or source files a client has given you.

What do I need?

A Windows, Mac or Linux computer with Python and ffmpeg. The first video downloads a speech model of about 500 MB.
